# Expense Tracker

## About
Short description of the project.

## Features
- User registration and login
- Add income and expenses
- Track current balance
- Savings
- Edit and delete transactions
- Transaction history
- Statistics and charts
- Date-based filtering

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Chart.js

## How It Works
Frontend → Fetch API → Express/Node.js → Mongoose → MongoDB

## What I Learned
- Building REST API endpoints
- Connecting a frontend to a backend
- CRUD operations
- MongoDB data modeling
- Authentication basics
- Handling asynchronous requests
- Deploying a full-stack application

## Known Limitations
- Passwords are currently stored without hashing.
- Authentication is implemented as a learning project and still needs stronger security.

## Future Improvements
- Password hashing
- Proper authentication with sessions/JWT
- Better input validation
- Improved error handling
- More transaction features
